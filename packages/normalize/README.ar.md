# @geoalgeria/normalize

**مفاتيح البحث لأسماء الأماكن الجزائرية، بالعربية وبالفرنسية. طيٌّ واحد في كل مكان.**

[![npm](https://img.shields.io/npm/v/@geoalgeria/normalize)](https://www.npmjs.com/package/@geoalgeria/normalize)
[![npm downloads](https://img.shields.io/npm/dm/@geoalgeria/normalize)](https://www.npmjs.com/package/@geoalgeria/normalize)
[![Code: MIT](https://img.shields.io/badge/Code-MIT-green.svg)](LICENSE)

</div>

<div dir="rtl">

كتابة `bejaia` يجب أن تجد **Béjaïa**، وكتابة `بجاية` يجب أن تجد **بِجَايَة**. لا يتحقق ذلك إلا إذا
ردّ كل برنامج في السلسلة الاسمَ إلى النص نفسه حرفًا بحرف: الموقع الذي يبحث في المتصفح، وبناء
الإصدار الذي يملأ فهرس النص الكامل، والهاتف الذي يبحث دون اتصال. هذه الحزمة هي ذلك الطيّ، ولا
شيء غيره. جزء من [GeoAlgeria](https://github.com/yasserstudio/geoalgeria).

</div>

```bash
npm install @geoalgeria/normalize
```

```js
import { conservativeKey, looseKey, tokenize, searchKeys, NORMALIZE_VERSION } from "@geoalgeria/normalize";

conservativeKey("Béjaïa");         // "bejaia"
conservativeKey("Sidi-Bel-Abbès"); // "sidi bel abbes"
conservativeKey("El M’Ghair");     // "el m ghair"
conservativeKey("بِجَايَة");           // "بجاية"
conservativeKey("الجـــزائر");        // "الجزاير"

looseKey("قسنطينة");                // "قسنطينه"
looseKey("مصطفى");                  // "مصطفي"
tokenize("Sidi-Bel-Abbès");        // ["sidi", "bel", "abbes"]

searchKeys("قسنطينة");
// { conservative: "قسنطينة", loose: "قسنطينه", tokens: ["قسنطينة"], looseDiffers: true }

NORMALIZE_VERSION;                 // 1
```

## المفتاح المحافظ

يحلّ **المفتاح المحافظ** الطرقَ المختلفة لكتابة الاسم الواحد، ولا يطوي شيئًا يغيّر الحرف الذي
يراه القارئ:

| القاعدة | مثال |
| --- | --- |
| أشكال العرض العربية تعود إلى حروفها الأصلية | `ﺃﺩﺭﺍﺭ` تصير `ادرار` |
| صور الألف (بهمزة فوقها أو تحتها، وبالمدّة، وألف الوصل) تصير ألفًا مجردة | `أدرار` و`إدرار` و`آدرار` و`ٱدرار` كلها `ادرار` |
| الهمزة على الواو أو الياء تُردّ إلى الحرف المجرد | `الجزائر` تصير `الجزاير` |
| التطويل يُحذف | `الجـــزائر` تصير `الجزاير` |
| الحركات وسائر العلامات العربية المركّبة تُحذف | `بِجَايَة` تصير `بجاية` |
| اللواحق اللاتينية تعود إلى حرفها الأصلي، مركّبةً كانت أو مفكّكة | `Béjaïa` تصير `bejaia` |
| اللاتينية الموسّعة أ وحروف اللاتينية الموسّعة ب المشكّلة تُطوى كذلك | `Bāb el Oued` تصير `bab el oued`، و`Ǧerǧer` تصير `gerger` |
| حرف البربرية اللاتينية يبقى حرفه ولا يفقد إلا كِبَره | `TAMAZIƔT` تصير `tamaziɣt` |
| الأرقام العربية الهندية والعربية الهندية الشرقية تصير أرقامًا لاتينية | `٣٤٥` و`۳۴۵` كلاهما `345` |
| صور الفاصلة العليا والشرطة تفصل بين الكلمات | `El M'Ghair` و`El M’Ghair` تصيران `el m ghair` |
| المسافات تُدمج، وحدود الكلمات تبقى داخل المفتاح | `  Oran   El Bahia ` تصير `oran el bahia` |
| حالة الأحرف تُردّ إلى الصغيرة | `SÉTIF` تصير `setif` |
| الحرف الذي لا يسمّيه أي جدول يبقى كما هو ولا يُحذف | `Tamaziɣt` تصير `tamaziɣt` |

## المفتاح الأوسع

**المفتاح الأوسع** هو المفتاح المحافظ مع مكافأتين اثنتين لا غير:

| القاعدة | مثال |
| --- | --- |
| الألف المقصورة والياء حرف واحد | `مصطفى` تصير `مصطفي` |
| التاء المربوطة والهاء حرف واحد | `قسنطينة` تصير `قسنطينه` |

فُصلتا عن المفتاح المحافظ حتى تُرتَّب المطابقة الناتجة عنهما دون المطابقة التامة بدل أن تكون
مثلها تمامًا. و`searchKeys` تخبر هل طُبّقت إحداهما فعلًا:

</div>

```js
searchKeys("تيزي وزو").looseDiffers; // false، المفتاحان نصّ واحد
searchKeys("قسنطينة").looseDiffers;   // true
```

## الكلمات ومجموعة الفواصل

المفتاحان كلاهما قائمةُ الكلمات موصولةً بمسافة واحدة، فتبقى الكلمة الأخيرة الناقصة قابلة
للإكمال، ولا يُطابَق الاستعلام أبدًا على سلسلة حروف ملتصقة طويلة. و`tokenize` هي ذلك التقطيع،
وعلى الفهرس الذي يبنيه المستهلك أن يوافقه حرفًا بحرف. تنتهي الكلمة عند هذه الرموز وحدها:

- المسافات: `U+0009` إلى `U+000D`، و`U+0020`، و`U+00A0`، و`U+1680`، و`U+2000` إلى `U+200A`،
  و`U+2028`، و`U+2029`، و`U+202F`، و`U+205F`، و`U+3000`؛
- صور الفاصلة العليا: `'` و`` ` `` و`ʼ` و`‘` و`’` (`U+0027`، `U+0060`، `U+02BC`، `U+2018`، `U+2019`)؛
- صور الشرطة: `-` و`U+2010` إلى `U+2015`.

وكل ما عداها إما مطويّ أو محذوف أو جزء من كلمته. أما الرموز غير المرئية، ومنها شرطة السطر
الاختيارية وعلامات اتجاه النص، فتُحذف ولا تُعامل حدودًا، لأنها ليست ما يراه القارئ. وعلامات
الترقيم ليست منها كذلك: الفاصلة تبقى داخل كلمتها، وتسجّل ذلك حالةٌ من المدوّنة، لأن سدّ هذه
الثغرة قاعدةٌ لا تحملها هذه الحزمة بعد.

## القواعد ومعرّفاتها

كل طيّ يحمل معرّفًا ثابتًا، مثل `ar.taa-marbuta-haa` أو `latn.extended-a`، وكل قاعدة تثبتها حالة
واحدة على الأقل من المدوّنة. المعرّفات هي الجزء الدائم: حالةُ المدوّنة، وسجلّ المراجعة، والمستدعي
الذي يسأل أي قاعدة صنعت المطابقة، كلها تسمّي النص نفسه.

وقاعدتان مرفوضتان صراحةً، ومسجّلتان كي لا تعودا في صمت: أداة التعريف العربية لا تُحذف أبدًا
(كون الاسم بالأداة والاسم بدونها يدلّان على المكان نفسه حقيقةٌ عن ذلك المكان لا عن الكتابة)، ولا
يُولَّد أي نقل حرفي لاتيني لاسم عربي (كتابةٌ لا يوفّرها أي مصدر هي اسم مختلق).

## الاستقلال عن بيئة التشغيل

مسار المفتاح يملك جداول نقاط الترميز الخاصة به. لا يستدعي شيئًا من آليات يونيكود في المحرّك،
ولا يستعمل أصناف الخصائص، ولا أي عملية تغيير حالة تابعة للغة المحلية، ولا يستورد أي وحدة أصلية
من المنصة، فيُنتج البايتات نفسها على Node وعلى الهاتف، ولا يمكن لترقية المحرّك أن تغيّر مفتاحًا
منشورًا في صمت. اختبارٌ يفرض ذلك بقراءة الشيفرة نفسها لا بالثقة في تعليق.

وتُعلن الجداول: ASCII، والملحق اللاتيني-1، واللاتينية الموسّعة أ وب، وعلامات التشكيل المركّبة،
والكتلة العربية، والملحق العربي، والعربية الموسّعة أ، وكتلتَي أشكال العرض العربية. داخل هذه
الكتل تُحذف العلامات وتُطوى الصور؛ أما الحروف التي هي حروف قائمة بذاتها، كغين البربرية
اللاتينية، والقاف المعقودة المغاربية في الملحق العربي، والباء الفارسية والفاء الثلاثية والكاف
المعقودة، فتبقى كما هي. والحرف الخارج عن كل كتلة معلنة يُردّ إلى الصغيرة إن كان حرفًا لاتينيًا
كبيرًا، وإلا مُرّر كما هو ولم يُحذف أبدًا.

الحزمة **بلا أي اعتماديات تشغيل**.

## المدوّنة المرجعية

المدوّنة هي العقد، وفيها 62 حالة. كل قاعدة أعلاه تثبتها حالةٌ واحدة على الأقل مبنية على اسم جزائري حقيقي،
ويستورد المستهلكون المدوّنة نفسها بدل كتابة حالاتهم الخاصة:

</div>

```js
import { corpus } from "@geoalgeria/normalize/fixtures";

for (const kase of corpus) {
  // kase.input, kase.conservative, kase.loose, kase.tokens, kase.proves, kase.note
}
```

## الإصدارات

`NORMALIZE_VERSION` هو الرقم الأكبر في نسخة الحزمة. أي تغيير فيما ترجعه دالة مفتاح لأي مدخل هو
إصدار **أكبر**، حتى لو كان تصحيح خلل، لأن المفاتيح مخبوزة في الفهارس المنشورة والفهرس المثبّت لا
يُرحَّل سجلًا سجلًا. إضافة تصدير جديد إصدار أصغر؛ التوثيق والأنواع ترقيع. ويثبّت المستهلكون نسخة
محددة بالضبط.
