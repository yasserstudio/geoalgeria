# نظرة عامة

3,795 صيدلية موزّعة على **67 ولاية**، من **OpenStreetMap** – كل سجلّ مُموقَع جغرافيًا، ثنائي اللغة (فرنسي/عربي) عند وجود اسم، مع الهاتف وساعات العمل ومؤشّر `dispensing` حيثما توفّر في OSM، إضافةً إلى الربط بالولاية/البلدية.

## التثبيت

```bash
npm install @geoalgeria/pharmacies
```

## بداية سريعة

```js
import {
  pharmacies,
  pharmacyById,
  pharmaciesByWilaya,
  metadata,
} from "@geoalgeria/pharmacies";

pharmacies().length; // 3795
pharmaciesByWilaya(16).length; // الجزائر العاصمة
pharmacyById("16-00001")?.commune;
metadata().wilayas_covered; // 67
```

## كيف تُبنى البيانات

تُوجَّه الأسماء بحسب الكتابة بصرامة: `name_ar` لا يحمل إلا العربية و`name_fr` لا يحمل إلا اللاتينية، حتى حين يخطئ OSM في الوسم. الوسم الذي يحمل أكثر من لغة في آن واحد («Pharmacie bouchekouf صيدلية بوشقوف») يُقطَع عند كل حدٍّ بين كتابتين، فيحفظ كل حقل نصفه الخاص ولا يكسب أيٌّ منها كلمة ليست في المصدر. التيفيناغ هي الكتابة الثالثة ولا تنتمي إلى أي من الحقلين: الاسم بالأمازيغية يبقى في `name`، أي الوسم الخام، بدل أن يُحذف أو يُصنَّف عربيًا.

وحيث يحمل OpenStreetMap صيدلية واحدة على هيئة عنصرين (عقدة ومخطّط مبنى، أو إملاءين مختلفين)، يُدمَج العنصران في سجل واحد. يكون العنصران صيدلية واحدة إذا كانا على مسافة أقل من 40 م وتشارك اسماهما **مفتاح اسم مرنًا**: كل نصف ناتج عن القطع بحسب الكتابة، مطويًّا عبر [`@geoalgeria/normalize`](../normalize) ومقارَنًا كمفتاح لا كنصٍّ معروض، مع إسقاط الكلمات التي لا تقول سوى «صيدلية». بهذا يُقرأ «Pharmacie Bouchekouf صيدلية بوشقوف» و«بوشقوف» المجرّد على ستة أمتار كسجل واحد. العنصر المحتفظ به يأخذ كل حقل ينقصه من العنصر الذي يحلّ مكانه، فلا يُفقد الدمج هاتفًا ولا عنوانًا ولا ساعات عمل ولا مؤشّر `dispensing`؛ وقيمته الخاصة هي التي تبقى حيث يذكر الاثنان قيمة، ولا يُدمَج نصّان معًا أبدًا.

## الدقة والتغطية

> **التغطية جزئية.** 3,795 صيدلية مُرسَّمة في OpenStreetMap مقابل ما يُقدَّر بنحو **~11,000 صيدلية** على المستوى الوطني (رتبة قدرٍ تقريبية – لا يوجد سجل رسمي مفتوح؛ بوابة المجلس الوطني للصيادلة خارج الخدمة). التغطية متفاوتة بين الولايات وأكثف في الشمال – هذه مجموعة يحرّرها المجتمع، **وليست سجلًّا رسميًا**.
>
> الإحداثيات نقاط OSM (مُعايَنة) أو مراكز مبانٍ (`geo_method`). البلدية أقرب مركز (بأفضل جهد)؛ الولاية دقيقة فعليًا. الأسماء والهواتف والساعات موجودة فقط حيث أدرجها مساهم في OSM.
